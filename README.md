# BasisCraft — мебельный конструктор

BasisCraft объединяет логику «Базис Мебельщик», «Базис Раскрой» и «Базис Смета» в одном веб-приложении. Введите размеры модулей, выберите материалы, получите деталировку, оптимизацию раскроя, подбор фурнитуры, смету, 3D/AI-превью и готовые экспортируемые спецификации.

## Возможности

- **Геометрический движок** — автоматический расчёт боковин, полок, перегородок, фасадов, задних стенок и ящиков с учётом толщин, зазоров и правил присадки.
- **Раскрой листов** — эвристический алгоритм оптимизации под формат 2800×2070 мм с учётом поворотов и статистики отходов.
- **Фурнитура и кромка** — автоматический подбор петель, направляющих, ручек, опор, конфирматов и подсчёт кромки 0.4/2 мм.
- **Смета** — детализированная калькуляция материалов, кромки, фурнитуры, труда, отделки, накладных и прибыли с настраиваемыми тарифами.
- **3D + AI рендер** — интерактивный превью на three.js и генерация изображений через OpenAI Images (GPT-Image) для согласований.
- **Экспорт** — выгрузка PDF «карточки изделия» и XLSX со всеми таблицами, сохранение проектов в Supabase (или локальное хранилище).

## Стек

- **Frontend**: Next.js 16 (app router), React 19, Tailwind CSS v4, three.js / @react-three/fiber.
- **Backend**: API routes на Next.js с алгоритмами на TypeScript.
- **База**: Supabase (Auth + таблица `projects`). Без переменных окружения проекты сохраняются в `data/projects.json` (файл создаётся автоматически).
- **AI**: OpenAI Images API (GPT-Image).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) и перейдите в раздел «Конструктор».

## Переменные окружения

Создайте `.env.local` и укажите необходимые ключи:

```bash
# AI рендеры
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=gpt-image-1 # опционально

# Supabase Auth + storage проектов (опционально)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=public-anon-key
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=service-role-key
```

- Если ключи OpenAI отсутствуют, API вернёт предупреждение, а интерфейс покажет только three.js превью.
- Если Supabase не настроен, проекты сохраняются локально, а блок авторизации подскажет как активировать вход.

### Структура таблицы Supabase

Создайте таблицу `projects` со схемой:

| Колонка        | Тип         | Описание                               |
|----------------|-------------|----------------------------------------|
| `id`           | `uuid`      | primary key, `uuid_generate_v4()`      |
| `specification`| `jsonb`     | полная спецификация изделия            |
| `updated_at`   | `timestamptz` | `now()` по умолчанию                 |

## Структура каталогов

```
app/
  constructor/        # рабочая станция мебельщика
  projects/           # список сохранённых изделий и Supabase Auth
  api/                # движок геометрии, раскроя, фурнитуры, экспорта, проектов
components/           # UI-модули (редактор модулей, таблицы, рендер и т.д.)
lib/
  geometryEngine.ts   # «Базис Мебельщик» логика
  cuttingEngine.ts    # «Базис Раскрой»
  hardwareEngine.ts   # «Базис Смета»
  costCalculator.ts   # калькулятор себестоимости
  exporters.ts        # PDF/XLSX генерация
  projectRepository.ts# Supabase / файловое хранилище
  store.ts            # Zustand состояние проекта
```

## Работа с проектами

1. Создайте или отредактируйте модули в `/constructor`.
2. Нажмите «Рассчитать», дождитесь обновления 3D, таблиц и сметы.
3. Экспортируйте PDF/XLSX или сохраните спецификацию в Supabase/файл.
4. Раздел `/projects` показывает историю проектов и блок авторизации Supabase.
